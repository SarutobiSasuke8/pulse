# PULSE

A 16-step drum machine in the browser. Kick, snare, hats, and perc, with tempo, swing, pattern banks, and a live playhead.

## Play

- **Play / Stop** — spacebar also works
- **Drag pads** to paint or erase a groove
- **Tempo / Swing / Level** — sliders in the transport
- **A–D banks** — A is house, B is boom-bap, C is a breakbeat, D is empty
- **Clear** and **Randomize** the current bank
- Tap a track name to **mute**
- Sign in to save named patterns to your library

Sounds are synthesized with the Web Audio API — no samples required.

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
npm run typecheck
```

React, TypeScript, TanStack Start, Tailwind v4.
